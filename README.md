Disables mouse acceleration in Windows and calculates the correct in-game sensitivity for your DPI and eDPI. Converts sensitivity values between games (CS2, Valorant, Apex, etc.).

## Features

- Disables Windows mouse acceleration (EnhancePrecision) in one click
- Sensitivity converter: paste CS2 sens → get Valorant equivalent
- Calculates eDPI from DPI + in-game sensitivity
- Tests current mouse polling rate
- Guides you to the right DPI for your mousepad size

## FAQ

**Does disabling acceleration feel weird at first?**  
Yes — if you're used to acceleration, the first few hours feel different. After a day, raw input is far more consistent.

**What DPI should I use?**  
400–800 DPI is most common among professional FPS players. Higher DPI reduces sensor smoothing at the cost of less precise micro-adjustments.
